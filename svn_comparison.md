#  1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка - это просто указатель на коммит (ссылка), создаётся мгновенно. В SVN ветка - это копирование директории на сервере, медленно и затратно.

#  2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN централизованная: все версии на одном сервере, коммит отправляется туда сразу. Без сети зафиксировать изменения в истории нельзя.


#  3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

Legacy-проекты (госсектор, банки), где миграция дорога.

Большие бинарные файлы (CAD, графика) - есть блокировка файлов (lock).

Жёсткий контроль доступа на уровне папок.

Простые линейные проекты в одной команде.
